# TinyOS Genesis 官网

纯静态站点，**无构建工具、无 npm 依赖、无 CDN 外链**。

## 本地打开

双击 `index.html` 即可。

或者起一个本地服务器（可选，行为完全一致）：

```bash
python -m http.server 8000
# 然后浏览器打开 http://127.0.0.1:8000/
```

## 文件

| 文件 | 说明 |
|---|---|
| `index.html` | 页面结构与全部文案（中英双语以 `data-zh` / `data-en` 属性成对标注） |
| `style.css` | 深色科技风样式、响应式布局、条形图与架构分层图 |
| `app.js` | 语言切换、终端打字机效果、体积条进场动画 |

## 实现要点

- **中英双语**：默认中文，选择存 `localStorage['tinyos-lang']`。切换时遍历
  `[data-zh][data-en]` 元素替换 `textContent`，并同步 `<html lang>`。
  HTML 里保留了中文兜底文案，缺 `app.js` 也能正常阅读。
- **终端演示**：`#demo` 里的内容由 `app.js` 逐字打出（普通字符 18ms、换行 28ms），
  带闪烁光标。**检测到 `prefers-reduced-motion: reduce` 时一次性输出**，不做动画。
- **体积对比条**：用 `IntersectionObserver` 在元素进入视口时才触发 CSS transition 增长；
  浏览器不支持时直接显示最终值。
- **无障碍**：语义化标签、`lang` 属性、键盘可达、尊重 `prefers-reduced-motion`。

## 文案约定（重要）

- **网页文案用中文没问题**（浏览器有中文字体）。
- 但**终端演示、命令、代码示例一律英文 ASCII** —— 因为 TinyOS 的 VGA 文本模式用
  CP437 字形表，显示不了汉字（且一个汉字占 3 格会把整行顶出 80 列）。
  这是项目本身的一个工程约束，站点里也把它当作卖点讲清楚了。

## 事实准确性

站点内容严格对照真实实现，**没有**写入项目不具备的功能。
早期资料里出现过的「JVM 运行时 / C·C++·Python·Java 工具链 / Docker 网页体验」
等描述与真实系统不符，**已确认不实**，因此未采用。
