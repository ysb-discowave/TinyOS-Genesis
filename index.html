产品介绍

TinyOS Genesis v0.1 是从零手写的裸机 x86 操作系统：可引导镜像约 612 KB，内置 tinysh 用户态 shell、Lua 5.4.7、图形文本桌面与网络组件。它不是 Linux，也不是 Linux 内核，全部从第一行汇编与 C 写起。下面按模块进入各个专题页。

  • tinysh 在线体验

    19 条命令的用户态 shell，登录后自动进入，可在线试玩真实会话。

    进入 →

  • 文件系统

    VFS 抽象 + 压缩只读 romfs，以及 ATA 多磁盘抽象层（含 MBR 分区表）。

    进入 →

  • 软件包管理器

    用户程序打包成自定义 TNCR 格式，由 TNCR 加载器载入用户态。

    e1000 网卡驱动；FTP 服务器/客户端、TinySMB、TCP socket、tcping。

为什么界面文案一律是英文？

          
图形桌面运行在 VGA 80×25 文本模式，字形表是 CP437（IBM PC 字符集），根本没有汉字字形；而且一个汉字要占 3 个字符格，会直接把一行顶出 80 列。这是有说服力的工程约束，不是偷懒。

快速上手（Windows）

        
构建与运行都由仓库内的脚本驱动（需要本机装有 zig 与 NASM）。下面是可参照的入口命令。


        

          
# 1) 安装交叉编译工具链（zig + NASM）
powershell -ExecutionPolicy Bypass -File tools\setup-toolchain.ps1

# 2) 构建用户态 TNCR 程序（tinysh / lua / 网络组件）
python tools\build_users.py

# 3) 构建可引导镜像 tinyos.img（约 612 KB）
powershell -ExecutionPolicy Bypass -File build.ps1

# 4) 启动到 QEMU
start.bat

        


        

          
首次启动：安装向导

          
镜像首次启动会跑 5 步安装向导（disk / network / software / accounts / confirm）。第 4 步 accounts 需设置 root 密码（≥3 位，输入两遍）。登录后自动进入 tinysh；exit 退回内核 shell（uname / mem / ps / disk / net / help / lua）。

        


        
提示：全部测试由 QEMU 串口自动化驱动，27/27 通过，无需人工点击。
